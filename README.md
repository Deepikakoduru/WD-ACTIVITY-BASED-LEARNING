## DESCRIPTION

This project consists of three webpages developed using basic HTML and CSS concepts.

**1. Personal Portfolio Website:**

Displays personal information, educational qualifications, technical skills, hobbies, projects, achievements, and contact information.

**2. College Fest Management Website:**

Displays technical events, cultural competitions, workshops, event schedules, coordinators, rules, and a registration form.

**3. Bus and Train Ticket Booking Interface:**

Displays source and destination fields, travel dates, passenger details, available bus and train services, fare information, and seat-selection layouts. It provides a simple interface for users to explore the basic process of booking travel tickets online.
